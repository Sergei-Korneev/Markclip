# Markclip — быстрые заметки в Markdown из трея

> English: [README.en.md](README.en.md)

Кроссплатформенное приложение для **Linux и Windows** (код также содержит
ветки для macOS) в системном трее: нажал глобальную комбинацию клавиш —
ввёл текст — Enter. Текст тут же дописывается в Markdown-файл. Удобно
для заметок на ходу: идей, ссылок, задач. Полностью портативно — папку
с программой можно просто переносить, в том числе на флешке, а в качестве
«хранилища» указать папку заметок **Obsidian** (см. ниже).

## Возможности

* **Глобальный хоткей** (по умолчанию `Ctrl+Alt+Space`) открывает компактное
  окно ввода в любом приложении.
* **Заметка одним движением**: текст → `Enter` или `Ctrl+Enter` → готово.
  `Escape` — закрыть без сохранения.
* **Умный `Ctrl+V`** (и `Shift+Insert`): одна команда вставки на всё —
  приложение смотрит, что в буфере: картинка → файл вложения и
  Markdown-ссылка в тексте, текст → обычная вставка.
* **Правка как в редакторе**: правый клик в полях заметки — контекстное
  меню «Вырезать/Копировать/Вставить/Выделить всё», те же действия на
  `Ctrl+X`/`Ctrl+C`/`Ctrl+V`/`Ctrl+A` (плюс `Ctrl+Insert`/`Shift+Insert`/
  `Shift+Delete`).
* **Картинки в заметке**: `Ctrl+V` вставляет картинку из буфера (скриншот,
  изображение из браузера). Файл сохраняется в `<папка заметок>/assets/`,
  в текст заметки падает Markdown-ссылка `![изображение](assets/...)`,
  а в окне ввода картинка сразу видна. Работает на Linux/X11, Windows
  и macOS.
* **Перетаскивание файлов**: бросьте файлы из файлового менеджера прямо
  в окно заметки — картинки вставляются как `![изображение](assets/...)`
  (с превью), остальные файлы ссылкой на своё вложение. Сами файлы
  копируются в папку вложений (`assets/`), имена сохраняются, чужие
  файлы не перезаписываются. Нужен пакет `tkinterdnd2` (устанавливается
  вместе с зависимостями).
* **Заголовок и имя файла** — необязательные поля прямо в форме заметки.
  Заполните их — и заметка сохранится отдельным файлом `<имя>.md`
  (заголовок — первой строкой `# ...`); оставьте пустыми — как раньше,
  дополнение в дневной `ГГГГ-ММ-ДД.md`. Имя подставляется из заголовка
  автоматически, пока вы не поправите его вручную. Поле «Имя файла»
  знает уже существующие заметки: список открывается по стрелке в поле
  (или клавише `Down`) и закрывается, как только вы начинаете печатать.
  Выберите файл — новый текст **допишется в его конец**, так
  можно продолжать любую заметку. Новое имя создаётся файлом, а имя,
  выведенное из пустого поля (по заголовку или времени), чужой файл не
  трогает — при совпадении добавляется суффикс `_2`. Эти поля можно
  заранее заполнить шаблонами: дата/время, первые N символов текста,
  первая ссылка (см. ниже).
* **Дневные Markdown-файлы** `ГГГГ-ММ-ДД.md` в папке из настроек; у каждой
  заметки время в заголовке `## HH:MM:SS`. Файлы открываются любым
  Markdown-редактором и синхронизируются как обычный текст.
* **Иконка в трее** (Linux и Windows) с меню: открыть окно, настройки, выход.
* **Настройки**: папка для заметок, хоткей, шаблоны заголовка, имени и
  текста новой заметки, имя папки вложений и язык интерфейса. Комбинацию
  не нужно печатать строчками — кнопка «Записать комбинацию» запоминает
  то, что вы нажали.
* **Языки интерфейса**: русский, английский, китайский — переключаются
  в настройках, меняют весь интерфейс сразу (см. «Языки»).
* **Портативность**: `config.json`, журнал `markclip.log` и папка заметок
  по умолчанию (`notes/`) лежат **рядом с самой программой** — папку можно
  просто перенести, включая на флешке.

Пример заметки:

```markdown
# Заметки за 2026-10-23

## 14:05:12

Позвонить Ивану по договору

## 14:07:41

Идея: https://example.com/статья про логистику

## 14:08:03

![изображение](assets/2026-10-23_140803.png)
```

## Требования

* **Python 3.10 или новее** (Linux, Windows).
* **Linux**: X11. В чистом Wayland глобальные хоткеи зависят от Xwayland
  и могут работать не везде (см. «Диагностику»).
* Для **полноценного меню трея на Linux** нужен PyGObject — установщик
  предупредит, если его нет.

## Установка

### Linux

```bash
./install.sh
```

Скрипт создаёт виртуальное окружение `.venv` и ставит зависимости. Если в
системе нет заголовков ядра (обычно так бывает с `evdev` — зависимостью
pynput), установщик сам поставит pynput без зависимостей: для глобальных
хоткеев в X11 это не нужно — используется бэкенд X11/RECORD.

Для полного меню трея поставьте в систему PyGObject (см. «Диагностику»).

### Windows

Запустите `install.bat` (Python должен быть в PATH; при установке Python
отметьте «Add python.exe to PATH»).

## Запуск

| Система | Команда |
|---|---|
| Linux | `./run.sh` |
| Windows | `run.bat` |

Ключи командной строки:

* `--note` (`-n`) — сразу открыть окно ввода заметки;
* `--settings` (`-s`) — сразу открыть настройки (запасной вход, если
  меню трея недоступно);
* `--version` — версия; `--help` — справка.

После запуска программа сидит в трее: иконка + хоткей.

## Настройки

Пункт **«Настройки…»** в меню трея:

* **Папка для заметок** — куда писать Markdown-файлы (по умолчанию
  `<папка программы>/notes`);
* **Хоткей** — комбинация для открытия окна. Кнопка **«Записать комбинацию»**
  запоминает следующее нажатие (например, вы нажимаете `F8` или
  `Ctrl+Alt+N`). Поддерживаются буквы, цифры, функциональные клавиши,
  стрелки, пробел и модификаторы `Ctrl`, `Alt`, `Shift`, `Win`. Символ `+`
  в комбинациях не поддерживается;
* **Заголовок по умолчанию** — шаблон, подставляемый в поле «Заголовок»
  при открытии пустой формы (черновик шаблон не трогает). Подстановки:
  `{date}` — 2026-10-23, `{time}` — 21-30-45, `{datetime}` —
  «2026-10-23 21-30-45», литеральная скобка — `{{`. Пусто — поле остаётся
  пустым. Подстановки по тексту (`{text}`, `{text:90}`, `{url1}` — см.
  ниже) применяются при сохранении, когда текст уже введён, поэтому поле
  при открытии они не заполняют;
* **Имя файла по умолчанию** — шаблон для поля «Имя файла» (те же
  подстановки, в том числе `{text:90}` — первые 90 символов текста заметки;
  имя нормализуется: запрещённые символы и переносы строк заменяются,
  края подчищаются, длина ограничивается). Пока шаблон задан, имя не
  следует за заголовком автоматически;
* **Шаблон текста заметки** — оборачивает введённый текст при сохранении:
  `{text}` — место текста, `{url1}` — первая ссылка `http(s)://` в нём,
  `{date}`/`{time}`/`{datetime}` — момент сохранения. Если `{text}` в
  шаблоне нет, текст дописывается в конец. Пусто (значение по умолчанию) —
  текст сохраняется как есть, время в тело не добавляется;
* **Папка вложений** — имя подпапки внутри папки заметок, куда падают
  картинки из буфера (по умолчанию `assets`);
* **Язык** — язык интерфейса: `Русский`, `English`, `中文`. Выбор
  применяется сразу при нажатии «Сохранить» — меняются открытые окна
  и меню трее.

Хранилище настроек — файл `config.json` **в папке самой программы**
(портативность). Оттуда же, `markclip.log`, — журнал для диагностики.
Для особых случаев папку состояния можно переопределить переменной
окружения `MARKCLIP_HOME` (используется и тестами):

```bash
MARKCLIP_HOME=/tmp/markclip-state ./run.sh
```

Хоткей, введённый вручную в `config.json`, приводится к каноническому виду
автоматически (`<ctrl>+<alt>+<n>` → `<ctrl>+<alt>+n`). Если комбинация
не применяется, на сессию временно включается `Ctrl+Alt+Space`, а ваш файл
настроек не переписывается.

## Языки

Интерфейс локализован на **русский** (базовый), **английский** и
**китайский**. Язык выбирается в настройках и хранится в `config.json`
(поле `language`). В переводе участвует весь интерфейс: окно заметки
и настройки, меню трея, сообщения об ошибках, справка `--help`;
заголовок дневного файла тоже пишется на выбранном языке
(`# Заметки за …` / `# Notes for …` / `# … 的笔记`).

Файлы языков лежат в папке `locales/` рядом с программой:

```
locales/
├── en.json   # English
└── zh.json   # 中文
```

**Добавить свой язык**: скопируйте любой файл, например
`locales/en.json` → `locales/de.json`, переведите значения (ключи —
исходные русские строки, их менять не нужно) и перезапустите программу —
язык сам появится в списке настроек. Незнакомые ключи и отсутствующий
файл означают возврат к русскому, ничего не ломается.

Замечания:

* в собранном `Markclip.exe` языки встроены в файл, но `locales/` рядом
  с exe имеет приоритет — можно править переводы без пересборки;
* для отображения китайского на Linux нужен установленный шрифт с CJK
  (например, `wqy-zenhei` или `noto-cjk`); в Windows шрифты системные,
  ничего доустанавливать не надо.

## Использование с Obsidian

Markclip пишет обычные Markdown-файлы без какой-либо привязки к формату
приложения, поэтому служит отличным «быстрым захватом» для базы знаний
в [Obsidian](https://obsidian.md):

1. В настройках укажите папкой для заметок папку вашего хранилища Obsidian
   (vault) или её подпапку — например, `~/Obsidian/База/Inbox`.
2. Заметки появляются в Obsidian сразу: Obsidian подхватывает изменения
   файлов на диске, ничего перезапускать не нужно.
3. **Именованные заметки** (поля «Заголовок»/«Имя файла») становятся
   готовыми страницами с H1-заголовком. **Дневные заметки** пишутся
   файлами `2026-10-23.md` — как у плагина Daily Notes.
4. Картинки из буфера лежат в подпапке `assets/` (имя меняется в настройках),
   ссылки в тексте относительные — Obsidian их открывает. Если хотите,
   чтобы картинки складывались в папку вложений самой Obsidian, настройте
   в ней «Attachments → Default location for new attachments».
5. Шаблоны из настроек делают быстрые заметки «готовыми» страницами:
   например, заголовок `Заметка {date}`, имя файла `{text:90}` (имя из
   первых 90 символов текста) и шаблон текста `{url1}\n\n{text}` —
   каждая вставка сохранится отдельной страницей с первой ссылкой сверху.

Совет: держите Markclip на автозагрузке и используйте его как «поле ввода»
для Obsidian — быстрый захват из любого приложения, а структурирование
и работа с базой остаются в Obsidian.

## Автозагрузка

**Linux** — файл `~/.config/autostart/markclip.desktop`:

```ini
[Desktop Entry]
Type=Application
Name=Markclip
Exec=/путь/к/markclip/run.sh
Terminal=false
```

**Windows** — ярлык на `run.bat` в папку
`shell:startup` (Win+R → `shell:startup`).

## Сборка переносимого приложения

Одним файлом через PyInstaller:

**Windows** (после `install.bat` и `.venv\Scripts\pip install pyinstaller`):

```bat
build_windows.bat
```

Готовый файл — `dist\Markclip.exe`; рядом с ним создадутся `config.json`,
`markclip.log` и `notes\`.

**Linux**:

```bash
.venv/bin/pip install pyinstaller
.venv/bin/pyinstaller --noconfirm --windowed --onefile --name Markclip \
    --collect-submodules pynput --collect-submodules pystray \
    --add-data "locales:locales" run.py
```

## Диагностика

Всё пишется в `markclip.log` рядом с программой.

* **В трее нет иконки (Linux).** Нужен работающий «хост трея»: в GNOME —
  расширение AppIndicator; в KDE он встроен; в тайловых WM (i3, sway) —
  trayer/stalonetray или полоса с tray. Проверить, есть ли хост:
  `xprop -root _NET_SYSTEM_TRAY_SELECTION` (X11) — пусто значит, хоста нет.
* **Меню трея недоступно / предупреждение при старте.** В системе нет
  PyGObject и используется урезанный бэкенд xorg (иконка без меню).
  Поставьте пакеты:

  | Дистрибутив | Команда |
  |---|---|
  | Fedora | `sudo dnf install python3-gi python3-gobject-gtk gir1.2-gtk-3.0 gnome-shell-extension-appindicator` |
  | Ubuntu/Debian | `sudo apt install python3-gi gir1.2-gtk-3.0 gir1.2-ayatanaappindicator3-0.1` |

  В любой момент настройки открываются и без меню: `./run.sh --settings`.
* **Хоткей не срабатывает (Wayland).** Глобальные перехваты клавиатуры
  работают через Xwayland: если приложение видно в `xdotool getactivewindow`,
  сработает. Иначе временно используйте X11-сессию или запускайте Markclip
  с ключом `--note`.
* **Окно не открывается при нажатии хоткея** — посмотрите `markclip.log`,
  там указана причина (например, комбинация занята другой программой).

## Тесты

```bash
.venv/bin/python tests/test_core.py
```

Проверяют нормализацию хоткеев, портативное хранение настроек, запись
Markdown-заметок (дневных и именованных), сохранение картинок, подстановку
шаблонов, отрисовку иконки, переводы интерфейса и полноту файлов языков
(сеть и дисплей не нужны).

## Структура проекта

```
markclip/
├── run.py            # точка входа
├── markclip/
│   ├── app.py        # главный класс: события, окно, настройки, запуск
│   ├── gui.py        # окно ввода заметки и окно настроек (Tkinter)
│   ├── tray.py       # иконка и меню трея (pystray)
│   ├── hotkey.py     # формат хоткеев, глобальный слушатель (pynput)
│   ├── clipboard.py  # чтение картинки из буфера обмена (Pillow)
│   ├── config.py     # config.json в папке программы (портативность)
│   ├── i18n.py       # языки интерфейса (tr, set_language)
│   ├── notes.py      # дневные и именованные заметки, картинки assets/
│   └── icons.py      # рисование иконки трея (Pillow)
├── locales/          # переводы интерфейса: en.json, zh.json
├── tests/test_core.py
├── install.sh / install.bat
├── run.sh / run.bat
└── build_windows.bat
```
